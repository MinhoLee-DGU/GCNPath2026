# GCNPath Pathway Importance Visualization Manual (`_barplot_importance_score.R`)

Visualize Grad-CAM pathway importance scores generated by GCNPath drug response models. This utility processes raw Grad-CAM score files, averages them across multiple seed models, maps cell and drug IDs to readable names, applies advanced dynamic scaling options, and exports vector SVG/PNG horizontal barplots (individual combinations) or comparative heatmaps (multi-combination matrices).

---

## 💻 CLI Usage Example

### Scenario A: Generate Individual Horizontal Barplots
Generate distinct horizontal barplots for selected cell lines and drugs, showing the top 10 positive pathway importance scores in descending order.

```bash
Rscript _barplot_importance_score.R \
  --gcam_file="results/IC50_GDSC/Normal/RGCN/pred_sclc_seed[0-9]+_gcam.csv" \
  --subset_cell="LB647-SCLC|NCI-H748" \
  --subset_drug="Etoposide|Cisplatin" \
  --anno_cells="data/cell_data/Anno_Cells.csv" \
  --col_anno_cells1="SANGER_MODEL_ID" \
  --col_anno_cells2="MODEL_NAME" \
  --anno_drugs="data/drug_data/Anno_Drugs.csv" \
  --col_anno_drugs1="Drug_CID" \
  --col_anno_drugs2="Name" \
  --n_bar=10 \
  --out_dir="sclc_importance_barplots"
```

*Note:*
- Cells in SCLC prediction outputs are identified using SANGER MODEL IDs. `--anno_cells` allows mapping these to readable cell line names (e.g. `LB647-SCLC` and `NCI-H748` instead of `SIDM00183` and `SIDM01117`).
- Drugs are identified using PubChem CIDs. `--anno_drugs` allows mapping these to readable names (e.g. `Etoposide` and `Cisplatin` instead of `36462` and `5702198`).
- Pattern `pred_sclc_seed[0-9]+_gcam.csv` matches multiple seed output files dynamically using regular expression syntax.

## 📥 Input & 📤 Output Description

```text
Rscript _barplot_importance_score.R \
  --gcam_file        [Input Grad-CAM Score File(s), CSV Format; Mandatory] \
  --col_cell         [Cell Column Name in -gcam_file; Default: 'Cell'] \
  --col_drug         [Drug Column Name in -gcam_file; Default: 'Drug'] \
  --subset_cell      [Cell Line ID(s) or Name(s) to Select, separated by '|'; Default: NULL] \
  --subset_drug      [Drug CID(s) or Name(s) to Select, separated by '|'; Default: NULL] \
  --anno_cells       [Input Cell Line Annotation File, CSV Format; Default: '_case_study/Anno_Cells.csv'] \
  --col_anno_cells1  [Cell ID Column Name in -anno_cells; Default: 'SANGER_MODEL_ID'] \
  --col_anno_cells2  [Cell Name Column Name in -anno_cells; Default: 'MODEL_NAME'] \
  --anno_drugs       [Input Drug Annotation File, CSV Format; Default: '_case_study/Anno_Drugs.csv'] \
  --col_anno_drugs1  [Drug CID/ID Column in -anno_drugs; Default: 'Drug_CID'] \
  --col_anno_drugs2  [Drug Name Column in -anno_drugs; Default: 'Name'] \
  --n_bar            [Number of Top Pathways to Display; Default: 10] \
  --scale            [Scaling Option: 'raw', 'zscore', 'softmax', 'sum', 'minmax'; Default: 'sum'] \
  --heatmap          [Generate Consolidated Heatmap (T/F); Default: FALSE] \
  --combination      [Verify all Cartesian combinations of subset cells and drugs (T/F); Default: FALSE] \
  --xlab_size        [Font Size for Heatmap X-Axis (Pathways); Default: 9] \
  --ylab_size        [Font Size for Heatmap Y-Axis (Cell x Drug); Default: 9] \
  --out_dir          [Output Plot Directory; Default: 'plots_importance'] \
  --width            [Output Plot Width in cm; Default: 15] \
  --height           [Output Plot Height in cm; Default: 10] \
  --dpi              [Plot DPI; Default: 500] \
  --svg              [Save Plots as SVG (T/F); Default: FALSE]
```

### Detailed Parameter Descriptions

#### Inputs
* **`--gcam_file`**: Path to the Grad-CAM importance file. Multiple files or regular expression patterns (e.g. `pred_sclc_seed[0-9]+_gcam.csv`) can be supplied. Multiple paths can be separated by `|`.
* **`--anno_cells` & `--anno_drugs`**: Annotation tables used to translate raw molecular identifiers into human-readable common names.

#### Scaling Methods (`--scale`)
* **`sum` (Relative Proportion)**: Recommended. Scales positive pathways relative to the total sum of importances per combination.
* **`zscore` (Z-Score Normalization)**: Standardizes importance values to highlight outlier high-contributor pathways.
* **`raw`**: No transformation; keeps raw Grad-CAM scores.
* **`minmax`**: Scales values to `[0, 1]` range.
* **`softmax`**: Applies exponential scaling (sums to 1).

#### Outputs
* **`sclc_importance_barplots/barplot_[Cell]_[Drug].png`** (or `.svg`): Clean horizontal barplot showing the top 10 pathway importance scores in descending order.
