# GCNPath Prediction vs. Actual Scatter Plot Manual (`_scatterplot_pred_actual.R`)

Generate high-quality, publication-ready scatter plots comparing predicted and actual drug sensitivity values (e.g., ln(IC50)) for the GCNPath AI model, with automated performance metrics and multi-seed aggregation.

---

## 💻 CLI Usage Examples

### Example A: GDSC1+2 Dataset in Cell-Blind Test Scenarios (Figure 5A)
Evaluate GCNPath predictions on the GDSC1+2 cell-blind scenario model prediction output:

```bash
Rscript _scatterplot_pred_actual.R \
  --pred_file="results/IC50_GDSC/Cell_Blind/RGCN/pred_test_0.csv" \
  --col_pred="Prediction" \
  --col_true="LN_IC50" \
  --out_file="pred_actual_gdsc_cell_blind_0.png"
```

### Example B: CCLE Dataset Predictions (Figure 5B)
Plot predictions on the CCLE dataset using wildcard/regular expression pattern to average prediction results across all seed models (seeds 2021 to 2030):

```bash
Rscript _scatterplot_pred_actual.R \
  --pred_file="results/IC50_GDSC/Normal/RGCN/pred_ccle_seed[0-9]+.csv" \
  --col_pred="Prediction" \
  --col_true="LN_IC50" \
  --col_cell="Cell_Primary" \
  --col_drug="Drug_CID" \
  --out_file="pred_actual_ccle.png"
```

*Note:*
- Setting `--aggregate_mean=TRUE` (default) aggregates the predictions from all matched seed files (`pred_ccle_seed2021.csv` to `pred_ccle_seed2030.csv`) by cell line and drug before plotting.

## 📥 Input & 📤 Output Description

```text
Rscript _scatterplot_pred_actual.R \
  --pred_file      [Path to Prediction CSV file(s); Supports wildcards and '|' separators; Mandatory] \
  --col_pred       [Prediction Column Name in --pred_file; Mandatory] \
  --col_true       [True/Actual Values Column Name in --pred_file; Mandatory] \
  --col_cell       [Cell Identifier Column Name; Required if --aggregate_mean=TRUE; Default: NULL] \
  --col_drug       [Drug Identifier Column Name; Required if --aggregate_mean=TRUE; Default: NULL] \
  --aggregate_mean [Whether to Aggregate Across Seeds/Folds (T/F); Default: TRUE] \
  --point_color    [Point Color Name/Hex code or Column Name for Dynamic Coloring; Default: 'black'] \
  --point_size     [Size of Scatter Points; Default: 1.5] \
  --point_alpha    [Transparency of Scatter Points [0, 1]; Default: 0.25] \
  --width          [Plot Width in cm; Default: 10] \
  --height         [Plot Height in cm; Default: 10] \
  --out_file       [Output Plot Path; Default: 'prediction_scatter_plot.pdf'] \
  --dpi            [Plot DPI; Default: 500] \
  --rasterize      [Rasterize Points layer in SVG outputs (T/F); Default: TRUE] \
  --title          [Main Title of the Plot; Default: NULL] \
  --xlab           [X-axis Label; Default: 'Actual ln(IC50)'] \
  --ylab           [Y-axis Label; Default: 'Predicted ln(IC50)'] \
  --fit_line       [Add Linear Regression Fit Line (T/F); Default: FALSE] \
  --xy_line        [Add Diagonal Reference Line y = x (T/F); Default: TRUE] \
  --show_stats     [Show Performance Metrics (PCC, SCC, RMSE) (T/F); Default: TRUE] \
  --stats_pos      [Position of Stats Box ('topleft', 'topright', 'bottomleft', 'bottomright'); Default: 'topleft']
```

### Detailed Parameter Descriptions

#### Inputs
* **`--pred_file`**: Points to one or more CSV files containing predictions generated by `test.py`. Wildcard patterns (e.g. `pred_ccle_seed[0-9]+.csv`) are matched using standard directory searching and regular expressions.

#### Performance Metrics
* The script calculates the **Pearson Correlation Coefficient (PCC)**, **Spearman Correlation Coefficient (SCC)**, and **Root Mean Squared Error (RMSE)** from prediction data and renders them inside a statistic label box.

#### Optimization (`--rasterize`)
* When rendering scatter plots with thousands of points into vector files (such as SVG/PDF), the script can rasterize the points layer while keeping the text and axes in vector format. This prevents viewer lag and keeps file sizes optimized.
